# Expo PWA

Aplicativo com Expo, React Native, TypeScript e Expo Router, preparado para priorizar a experiência web/PWA.

## Requisitos

- Node.js LTS
- npm

## Executar localmente

```bash
npm install
npm run web
```

Para iniciar o Expo no modo padrão, execute `npm start`.

## Estrutura inicial

- `app/`: rotas e telas do Expo Router.
- `src/components/`: componentes compartilhados.
- `src/services/`: serviços de acesso a dados (a implementar nos próximos checkpoints).
- `src/types/`: tipos TypeScript compartilhados.
- `src/utils/`: utilitários compartilhados.

A configuração do Firebase/Firestore, o CRUD e os detalhes específicos de instalação PWA serão implementados em checkpoints posteriores.
